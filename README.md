# Проект "Маскировка банковских карт и счетов"

## Описание:

Проект "Маскировка банковских карт и счетов" - это веб-приложение на Python для маскирования персональных данных пользователей банковских карт и счетов. Пользователи могут не переживать за сохранность и безопасность своих персональных данных.

## Установка:

* Клонируйте репозиторий:
```
git@github.com:Asta88888/Homework.git
```

* Активируйте окружение Poetry:

В терминале, находясь в корневой папке проекта, активировать виртуальное окружение через poetry

* Установите Poetry:

В случае отсутствия менеджера проектов _poetry_, выполнить установку пакетов через _pip_ из списка зависимостей в файле __pyproject.toml_ 


## Запуск:

1. python main.py - из корня репозитория проекта
2. python <_path_>main.py - из другой папки 
3. <_path_> - путь к файлу main.py проекта Home_work_module_2

## Тестирование:

Ко всем модулям проекта добавлено тестирование (находится в директории tests). Просмотреть насколько процентов покрыт проект тестами можно набрав в терминале команду: 
pytest --cov-report term-missing --cov
